## Prerequisites

- **Node.js 22.22+**
- **Bun 1.2+** (recommended package manager)

<Step>

### Install

Add the CLI as a dev dependency:

<Tabs items={["bun", "npm", "pnpm", "yarn"]}>
<Tab value="bun">

```bash
bun add -d @stdout-design/cli
```

</Tab>
<Tab value="npm">

```bash
npm install -D @stdout-design/cli
```

</Tab>
<Tab value="pnpm">

```bash
pnpm add -D @stdout-design/cli
```

</Tab>
<Tab value="yarn">

```bash
yarn add -D @stdout-design/cli
```

### Scaffold a project

```bash
npx @stdout-design/cli init
```

`init` walks you through a few prompts project name, which starter templates to include, which locales to set up, whether to initialize git, and whether to install dependencies. Pass `-y` to skip prompts and use the defaults.

> If `studio.config.ts` already exists in the target directory, `init` skips scaffolding entirely.

`init` creates:

<Files>
  <File name="studio.config.ts" />
  <File name="README.md" />
  <File name="package.json" />
  <File name="tsconfig.json" />
  <File name="types.d.ts" />
  <Folder name="templates" defaultOpen>
    <File name="launch-hero.tsx" />
    <File name="bento-feature.tsx" />
    <File name="retro-poster.tsx" />
    <File name="trend-poster.tsx" />
  </Folder>
  <Folder name="locales" defaultOpen>
    <File name="en.json" />
    <File name="ar.json" />
  </Folder>
</Files>

- `studio.config.ts` the template registry, presets, and Google Fonts.
- `types.d.ts` adds the `tw=` attribute type for React.
- `templates/` your TSX components.
- `locales/` translation files, keyed by template id.

You get four starters: `launch-hero` (a streetwear landing page), `bento-feature` (a product bento grid), `retro-poster` (a cassette print poster), and `trend-poster` (an editorial six-item grid). Each one lays out at both presets, `instagram-square` (1080×1080, the default) and `x-card` (1200×675), and mirrors itself when rendered in Arabic. They're yours to rewrite or delete.

</Step>
<Step>

### Render your first image

```bash
npx @stdout-design/cli render launch-hero --headline "Hello there"
```

By default `render` outputs one PNG per locale in the config's `locales` (the ones you picked at `init`), at the config's `defaultPreset`. Pass `--preset all` for every preset. The files are named like:

```
out/launch-hero.en.instagram-square.0.png
out/launch-hero.ar.instagram-square.0.png
```

It also writes a `manifest.json` alongside the images summarizing what was rendered.

The Arabic file is the same template laid out right to left. To render one locale, pass `--locale`:

```bash
npx @stdout-design/cli render launch-hero --locale ar
```

</Step>
<Step>

### Open the live studio

```bash
npx @stdout-design/cli dev
```

This starts the dev server on `http://localhost:3030` with a live preview, an auto-generated prop panel, preset tabs, and locale switching. See [Live Studio](/docs/dev-studio) for the full walkthrough.

</Step>
</Steps>

## Project structure

<Files>
  <File name="studio.config.ts" />
  <Folder name="templates" />
  <Folder name="data" />
  <Folder name="locales" />
  <Folder name="out" />
  <Folder name=".studio-cache" />
</Files>

- `studio.config.ts` template registry, presets, locales, fonts.
- `templates/` one `.tsx` file per template. See [Writing Templates](/docs/templates).
- `data/` CSV or JSON files for data-driven batch rendering. See [Batch Rendering](/docs/batch-rendering).
- `locales/` per-locale translation JSON. See [Internationalization](/docs/internationalization).
- `out/` rendered assets (gitignored).
- `.studio-cache/` render cache (gitignored).

`out/` and `.studio-cache/` are gitignored by the scaffold and rebuilt as needed.
