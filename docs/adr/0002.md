# ADR 0002 — Batch pipeline module audit

**Status:** superseded

**Closed:** ADR 0001 renames were completed without incident. The batch pipeline audit was deferred and is no longer a priority — the existing structure is coherent enough to ship with. If performance or maintainability issues emerge in `core/src/batch/`, a new ADR should be opened with measured evidence rather than structural suspicion.

**Context:** per ADR 0001 §10, `core/src/batch/` has nine files for one end-to-end concept (running `studio render`). This is a candidate for consolidation, pending an audit of each file's actual cohesion.

**Files under audit:**

| File            | Assessment                                                |
| --------------- | --------------------------------------------------------- |
| `batch.ts`      | Orchestrator — runs the batch loop, calls everything else |
| `loaders.ts`    | Config + template + data file loading                     |
| `manifest.ts`   | Manifest writing                                          |
| `matrix.ts`     | Matrix expansion (rows × locales × presets)               |
| `naming.ts`     | Deterministic output filename generation                  |
| `render-one.ts` | Single render with cache                                  |
| `single.ts`     | `renderComponent` — thin wrapper                          |
| `types.ts`      | Shared types                                              |
| `utils.ts`      | Shared utilities (ensureDir, tryWriteFile)                |

**Likely merge candidates:** `loaders.ts` + `single.ts` + `render-one.ts` may be one linear per-row execution path that doesn't need separate files.

**Decision:** not resolved. Revisit after the ADR 0001 renames are settled.
